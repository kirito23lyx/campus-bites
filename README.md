# 食间 · Campus Bites

一个无需登录、没有后端的校园美食推荐网页。使用原生 HTML、CSS 和 JavaScript 编写，可以直接部署到 GitHub Pages。

## 功能

- 25 项演示菜单：15 道校园菜品和 10 款广式早茶。
- 每道菜一张对应的真实照片，提供来源、作者和授权说明。
- 分类、预算上限、食堂、口味、关键词组合筛选。
- 价格排序、菜名排序和推荐排序。
- 从当前筛选结果中随机推荐，多于一个候选时避免连续重复。
- 收藏、取消收藏、仅看收藏；使用 localStorage 在当前浏览器保存，支持同源多标签页同步。
- 菜品详情弹窗、空结果提示、手机布局和键盘操作。

## 本地运行

需要 Node.js 18 或更新版本。运行网页无需安装任何第三方依赖：

```sh
npm start
```

浏览器打开终端显示的 `http://127.0.0.1:4173`。也可用 VS Code 的静态网页服务器打开项目。不要直接双击 HTML 文件，因为浏览器的本地文件策略可能拦截 JavaScript 模块。

## 测试

```sh
npm test
```

完整浏览器检查（开发依赖仅用于测试）：

```sh
npm ci
npm run test:browser
```

Windows 上自动使用已安装的 Chrome 或 Edge。其他系统先运行 `npx playwright install chromium`。检查涵盖25张照片、组合筛选、搜索、排序、收藏刷新后恢复、随机推荐约束、无结果状态、手机布局、弹窗和图片授权页。

## GitHub Pages

在仓库 Settings → Pages 中，将 Source 设为 Deploy from a branch，选择 `main` 分支和 `/ (root)`。所有资源均使用相对路径，支持项目型 Pages 的子目录地址。`.nojekyll` 告诉 Pages 直接托管静态文件。

公开访问不需要本机保持开机。收藏保存在每位访问者自己的浏览器中，不跨设备同步。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` / `styles.css` | 页面结构和响应式样式 |
| `app.js` | 页面交互与状态管理 |
| `menu.js` | 25 项菜单数据与分类 |
| `logic.js` | 筛选、排序、随机推荐和收藏读写 |
| `assets/food/` | 25 张菜品实拍图片 |
| `photos.js` / `image-credits.json` | 照片与来源信息 |
| `credits.html` | 公开图片署名和授权页面 |
| `scripts/serve.mjs` | 仅供本机预览的静态服务器 |
| `tests/` | 功能逻辑与浏览器检查 |

## 数据与图片

菜名用于演示。价格、份量、食堂和窗口位置均为示例数据，不代表任何学校的真实菜单或供餐情况。照片可能展示单独的主菜，而非配饭套餐的全部内容。页面不包含订餐、支付和实时库存。

照片来自 Wikimedia Commons，按各张照片的原始许可使用，详见网站底部“图片来源与授权”和 `image-credits.json`。应用自身不会向第三方发送收藏记录，也不调用 AI 模型或付费 API。
